# YarnVault

YarnVault enables real-time data synchronization across distributed, containerized workflows, providing a unified service platform for scalable, concurrent collaboration.

YarnVault is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/YarnVault.git`
2. `cd YarnVault`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
